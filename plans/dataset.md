### Extraction Setting

**Do NOT extract images into markdown.** Use docling with image extraction disabled:

```python
from docling.document_converter import DocumentConverter

converter = DocumentConverter()
result = converter.convert("https://example.com/page")
# Export markdown WITHOUT embedded images
markdown_text = result.document.export_to_markdown(image_mode="placeholder")
```

Images will be downloaded separately using `wget` or `requests` and stored in `data/images/`.

## Extraction Tool: docling

**docling** - Document AI library for parsing documents to Markdown.

### Installation
```bash
pip install docling
```

### Supported Formats
- PDF → Markdown
- HTML/Web pages → Markdown
- DOCX → Markdown
- PPTX → Markdown

### Example Usage
```python
from docling.document_converter import DocumentConverter

converter = DocumentConverter()
result = converter.convert("https://example.com/document.pdf")
markdown_text = result.document.export_to_markdown()
```

### Advantages
- Preserves headings and structure
- Handles tables
- Extracts from URLs directly
- No manual HTML parsing needed
